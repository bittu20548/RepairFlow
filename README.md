# RepairFlow Backend

Backend API for RepairFlow, a multi-shop repair management SaaS.

## Tech Stack
- Node.js
- Express.js
- TypeScript
- PostgreSQL (Neon)
- Prisma ORM

## Features
- Shop management
- Customer management
- Device management
- Repair ticket management
- Repair status tracking

## Installation

```bash
npm install
```

## Environment Variables

Create a `.env` file:

```env
DATABASE_URL="your_database_url"
PORT=5050
```

## Run Development Server

```bash
npm run dev
```

## API Base URL

`http://localhost:5050`
